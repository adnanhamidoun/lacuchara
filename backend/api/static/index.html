⚙️ Configuration

To replace this file with your React frontend:

  1. Build your frontend: npm run build
  2. Copy the files into backend/api/static/
  3. Make sure index.html is at that folder root
  4. Restart the API - FastAPI will serve your frontend automatically

🐳 Docker

To deploy with Docker:

docker-compose up --build - Run locally

./scripts/deploy/azure-deploy.sh - Deploy to Azure
