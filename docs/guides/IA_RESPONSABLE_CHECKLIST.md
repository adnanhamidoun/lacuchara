# Responsible AI Checklist

## Product
- [ ] Disclosure text is visible where predictions are shown.
- [ ] User can continue operating without AI output.

## Engineering
- [ ] Failure handling is explicit and logged.
- [ ] Dependencies and fallbacks are documented.
- [ ] Monitoring is configured for key endpoints.

## Compliance
- [ ] Data collection is minimized.
- [ ] Retention and access policy is documented.
